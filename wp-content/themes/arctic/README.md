# Arctic Spas

## Arctic Spas WordPress Theme

Initial fork of the Baspa custom WordPress theme for the new Arctic Spas site.

This theme intentionally keeps the Baspa structure, templates, modules and sizing system as the technical baseline. Arctic-specific work should happen here, not in the reference `baspa.cz/` folder.

Notes:

- Original function prefixes and text references may still use `baspa_*` during the first fork stage.
- External Baspa theme updates are disabled in this fork.
- Figma wireframes define architecture; Figma graphics define branding/CSS/assets.
