## Poznamka

Pro automatizovane cteni vrstev, stylu a export obrazku pres Figma REST API bude potreba Figma API token s opravnenim ke cteni techto souboru.

Token se nema ukladat do repozitare ani posilat v chatu. Pokud bude potreba, ulozit lokalne do `.env.local`, napriklad:

```env
FIGMA_TOKEN=...
```
